# DDM — Built to Own

Corporate website for DDM, a fictional holding company spanning clubs, luxury residences, private companies, technology and public markets. It includes an interactive events calendar (`calendar.html`).

**Stack:** HTML, CSS, vanilla JavaScript

## Run locally

Static site with no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
